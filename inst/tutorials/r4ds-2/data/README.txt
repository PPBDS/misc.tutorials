us_births_1994_2014.xlsx
  US daily birth counts, 1994–2014. One row per calendar day; five columns:
  year, month, date_of_month, day_of_week (character, FiveThirtyEight-style
  labels: "Mon", "Tues", "Wed", "Thurs", "Fri", "Sat", "Sun"), births (int).
  Source: FiveThirtyEight R package (US_births_1994_2003, US_births_2000_2014),
  which in turn draws on CDC NCHS (1994–1999) and SSA card-application records
  (2000–2014). License: CC-BY.
  Article: https://fivethirtyeight.com/features/
    some-people-are-too-superstitious-to-have-a-baby-on-friday-the-13th/
  Raw source: https://github.com/fivethirtyeight/data/tree/master/births
  Note: post-2014 daily birth counts are not available in any public-use
  dataset (CDC NCHS public-use files suppress day of birth; CDC WONDER does
  not expose day-of-month grouping).

  Generated by explorations/us-births-heatmap/build-xlsx.R in the
  dataset-search project:

  library(dplyr)
  library(writexl)
  library(fivethirtyeight)

  births <- bind_rows(
    US_births_1994_2003 |> filter(year < 2000),
    US_births_2000_2014
  ) |>
    mutate(day_of_week = as.character(day_of_week)) |>
    select(year, month, date_of_month, day_of_week, births) |>
    arrange(year, month, date_of_month)

  writexl::write_xlsx(births,
    "inst/tutorials/r4ds-2/data/us_births_1994_2014.xlsx")
